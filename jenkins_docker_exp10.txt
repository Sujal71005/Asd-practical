1. Requirements
- Jenkins installed and running
- Docker Desktop running
- Git installed
- GitHub repository containing the web application and Jenkinsfile
- Jenkins configured to access Docker
Open Jenkins:
http://localhost:8080


Important: Since your Jenkins runs as a Windows service, make sure the service account can execute Docker commands. Docker working in your own terminal does not automatically mean Jenkins can access it.
2. Create the project folder
Open PowerShell:
mkdir docker-jenkins-practical
cd docker-jenkins-practical
npm init -y
npm install express
mkdir public


The project structure should be:
docker-jenkins-practical/
├── package.json
├── package-lock.json
├── server.js
├── Dockerfile
├── Jenkinsfile
└── public/
    └── index.html


3. Create server.js
const express = require("express");
const path = require("path");

const app = express();
const PORT = process.env.PORT || 3000;

app.use(express.static(path.join(__dirname, "public")));

app.get("/", (req, res) => {
    res.sendFile(
        path.join(__dirname, "public", "index.html")
    );
});

app.listen(PORT, "0.0.0.0", () => {
    console.log(`Web app running on port ${PORT}`);
});


4. Configure package.json
Make sure the scripts section contains:
"scripts": {
  "start": "node server.js"
}


Keep the dependencies generated by npm install.
5. Create the web page
Create public/index.html:
<!doctype html>
<html>
<head>
    <meta charset="utf-8">
    <title>Jenkins Docker Deployment</title>
</head>
<body>
    <h1>Jenkins + Docker Deployment</h1>
    <p>Web application deployed successfully!</p>
</body>
</html>


6. Create the Dockerfile
Create a file named exactly Dockerfile in the project root:
FROM node:20-alpine

WORKDIR /app

COPY package.json package-lock.json ./
RUN npm ci

COPY server.js ./
COPY public ./public

EXPOSE 3000

CMD ["npm", "start"]


This Dockerfile uses npm ci to install dependencies from the lockfile.
7. Create the Jenkinsfile
Create a file named exactly Jenkinsfile in the project root:

pipeline {
    agent any

    stages {
        stage('Checkout') {
            steps {
                checkout scm
            }
        }

        stage('Build Docker Image') {
            steps {
                bat 'docker build -t practical-web-app:latest .'
            }
        }

        stage('Stop Old Container') {
            steps {
                bat 'docker rm -f practical-web-app-container || exit /b 0'
            }
        }

        stage('Deploy Container') {
            steps {
                bat 'docker run -d --name practical-web-app-container -p 3001:3000 practical-web-app:latest'
            }
        }

        stage('Verify Deployment') {
            steps {
                bat 'docker ps'
            }
        }
    }
}

8. Test Docker manually first
Before running Jenkins, check that Docker can build and run the application.
docker build -t practical-web-app:latest .


Run the container:
docker run -d --name practical-web-test -p 3001:3000 practical-web-app:latest


Open:
http://localhost:3001/


If the page works, remove the test container:
docker rm -f practical-web-test


9. Push the project to GitHub
From the project folder:
git init
git add .
git commit -m "Add Docker deployment pipeline"
git branch -M main
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git push -u origin main


Replace the URL with your actual GitHub repository URL.

If the repository is already initialized and connected to GitHub, don't repeat git init or git remote add origin. Just commit and push your changes.
10. Configure the Jenkins job
1. Open Jenkins.
2. Click New Item.
3. Enter the job name:
   
   Jenkins-Docker-Deployment
4. Select Pipeline and click OK.
5. Scroll to the Pipeline section.
6. Choose Pipeline script from SCM.
7. Select Git.
8. Enter your GitHub repository URL.
9. Set Branch Specifier to:
*/main


10. Set Script Path to:
Jenkinsfile


11. Click Save.
11. Run the pipeline
1. Open the Jenkins-Docker-Deployment job.
2. Click Build Now.
3. Open the build in Build History.
4. Click Console Output.
5. Check that all pipeline stages succeed.
12. Verify the deployed application
Check the running container:
docker ps


Check application logs:
docker logs practical-web-app-container


Open the deployed website:
http://localhost:3001/
